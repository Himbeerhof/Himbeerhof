# Pontaj Himbeerhof

Aplicație Android pentru orele angajaților (Capacitor + Firebase).
Ramura `pontaj-app` — la fiecare push, GitHub Actions compilează APK-ul și îl publică în Releases.

- `src/app.js` — aplicația
- `src/firebase-config.js` — datele proiectului Firebase
- `firestore.rules` — regulile de securitate (se copiază în Firebase Console → Firestore → Rules)
